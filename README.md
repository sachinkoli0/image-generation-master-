# Image Generation Master

A creative prompt-engineering skill by Sachin Chittoriya.

Image Generation Master helps turn rough ideas and visual references into detailed, production-oriented prompts, with attention to concept development, composition, camera language, lighting, styling, visual consistency, and iterative refinement.

## Included
- The original skill source, preserved verbatim from the private plugin.
- Guidance for image concepts, fashion/editorial work, photography, digital art, and prompt refinement.

## Use
Import the skill in a compatible assistant environment, then describe the image you want to create. Include reference images and constraints when available.
