- **4K/8K**: Ultra-high definition for large displays

- **JPEG**: Photographs, web use
- **PNG**: Transparency, lossless quality

## Copyright & Legal Guidelines

### Safe Practices
- **Original Characters**: Create unique personas, not existing celebrities
- **Generic Inspiration**: Use styles as reference, not direct copies
- **Public Domain**: Classic art, mythology, folklore
- **Creative Commons**: Attribution-required assets
- **Fair Use**: Commentary, parody, educational purposes
- **Trademark Avoidance**: No logos, brand names, registered characters

### Risky Areas to Avoid
- Celebrity likenesses without permission
- Existing copyrighted characters (Disney, Marvel, etc.)
- Brand logos and trademarks
- Stock photo watermarks
- Private property without releases
- Recognizable buildings with restrictions

## Reducing False Positives in Fashion/Modeling Content

*Based on community solutions from Reddit and professional forums*

### Understanding Why Legitimate Fashion Gets Flagged

AI safety systems use multiple detection layers that can trigger false positives on professional fashion content:

**Layer 1: Keyword Blocklist**
- Scans for terms like "bikini," "lingerie," "underwear" before generation
- Cannot be explained by the AI when triggered
- **Solution:** Use professional alternatives (see below)

**Layer 2: Semantic Review**
- Analyzes context and intent
- Triggered by combinations like "young" + "woman" + "swimwear"
- **Solution:** Add explicit professional context

**Layer 3: Visual Classifier**
- Scans generated images for skin exposure
- Can flag even with clean prompts
- **Solution:** Adjust framing, pose descriptions, and artistic style

---

### Proven Strategies from Professional Community

#### Strategy 1: Professional Creative Brief Format
**Instead of:** "Woman in bikini on beach"
**Use:** "Professional e-commerce swimwear catalog photo of adult female model, neutral standing pose, studio lighting, product-focused composition, no suggestive styling, commercial retail photography"

**Key elements:**
- Explicit professional purpose
- Adult age specification
- Negation of risky terms ("no suggestive...")
- Commercial context

#### Strategy 2: Semantic Replacements
| Risky Term | Professional Alternative |
|------------|-------------------------|
| Bikini | Two-piece swimwear, swim set |
| Lingerie | Intimate apparel, undergarment |
| Underwear | Base layer, undergarment |
| Sexy | Elegant, sophisticated, refined |
| Hot | Striking, bold, vibrant |
| Seductive | Alluring (in fashion context), captivating |

#### Strategy 3: Context Reframing
**Add professional signals:**
- "Fashion editorial for [magazine type]"
- "E-commerce product photography"
- "Lookbook campaign"
- "Retail catalog image"
- "Commercial advertising"
- "Professional model portfolio"

#### Strategy 4: Age & Maturity Markers
**Problem:** "Young woman" triggers minor-safety filters

**Solutions:**
- State age explicitly: "32-year-old woman," "adult model in her 30s"
- Add adult context: "professional setting," "business attire," "confident posture"
- Use: "Woman" instead of "Girl," "Young woman," "Teen"
- Replace "Petite" with "Slim" or "Slender"

#### Strategy 5: Style-Based Solutions
**When photorealistic keeps failing:**

| Photorealistic | Alternative Style |
|---------------|-------------------|
| Photo | Editorial fashion illustration |
| Realistic | 2D vector fashion sketch |
| 4K photo | Flat lay product illustration |
| Cinematic | Technical fashion drawing |

**Note:** Visual classifier is less sensitive to illustrated/stylized skin

#### Strategy 6: Framing & Composition Adjustments
**High-risk compositions:**
- Rear-view poses
- Close-up torso shots
- Wet fabric descriptions
- Reclining/lying poses
- Bedroom settings

**Safer alternatives:**
- Full-body standing pose
- Three-quarter view
- Studio environment
- Product-focused framing
- Neutral backgrounds

#### Strategy 7: Explicit Negations
Include "no" statements to clarify intent:
- "No nudity"
- "No transparent fabric"
- "No suggestive pose"
- "No erotic styling"
- "Professional, commercial context only"

#### Strategy 8: Fresh Conversation Start
- If a chat has multiple flags, start a new conversation
- Cumulative context can increase rejection probability
- Don't edit flagged prompts repeatedly—rewrite from scratch

### Troubleshooting Decision Tree

**Error: "Prompt may violate guardrails" (before generation)**
→ Layer 1 or 2 triggered
→ Solution: Replace keywords, add professional context, start new chat

**Error: "Image created may violate guardrails" (after 20-40 seconds)**
→ Layer 3 visual classifier triggered
→ Solution: Adjust pose, framing, clothing description, try illustration style

**Error: "Lightly sexual or provocative themes"**
→ Borderline case
→ Solution: Add more professional context, use explicit negations, adjust composition
